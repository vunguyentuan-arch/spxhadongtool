# Holding & Thanh Lý Dashboard

**SPX Express · Hà Đông 9 HUB**

Dashboard quản lý đơn Holding và Thanh lý — React + Tailwind + Recharts, bundled thành single HTML.

## Tính năng

- Tổng quan — KPI cards + biểu đồ xu hướng 14 ngày
- App1 — Đơn cần chuyển Holding
- App2 — Đơn Holding chuyển thanh lý
- Sổ đối soát — Đơn rời Holding khi quá hạn
- Import CSV — Drag & drop upload
- Dark/Light mode toggle
- Responsive mobile

## Deploy Cloudflare Pages

1. Vào https://pages.cloudflare.com -> Create project -> Connect to Git
2. Chọn repo spxhadongtool
3. Build settings: để trống (static file)
4. Deploy -> nhận URL spxhadongtool.pages.dev

## Tech
React 18 + TypeScript + Tailwind CSS + Recharts + Framer Motion + Be Vietnam Pro font
